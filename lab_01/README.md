## Цель работы. Изучение основных принципов работы с ETL-инструментами на примере Pentaho Data Integration (PDI), настройка среды, создание конвейера обработки данных (фильтрация, очистка, замена значений) и выгрузка результатов в базу данных MySQL.

### Источник данных: https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

### Описание данных

Для анализа использовался набор данных о цепочках поставок, предоставленный компанией DataCo Global. Этот набор данных позволяет использовать алгоритмы машинного обучения и программное обеспечение R.
Области важных зарегистрированных видов деятельности: снабжение, производство, продажи, коммерческое распределение. Он также позволяет сопоставлять структурированные и неструктурированные данные для генерации знаний.

#### Ключевые идентификаторы:
* Order Id — уникальный номер заказа (может повторяться, если в заказе несколько товаров)
* Order Item Id — уникальный номер позиции в заказе (уникален для каждой строки)
* Order Customer Id — идентификатор клиента, сделавшего заказ
* Product Card Id — идентификатор товара

Даты:
* order date (DateOrders) — дата и время оформления заказа (формат: месяц/день/год часы:минуты)
* shipping date (DateOrders) — дата и время отгрузки заказа

Финансовые показатели:
* Sales — сумма продажи (количество × цена со скидкой)
* Benefit per order — прибыль с заказа (может быть отрицательной при убытке)
* Order Item Discount — сумма скидки на данную позицию
* Order Item Product Price — цена единицы товара без скидки
* Order Profit Per Order — еще один показатель прибыли (часто дублирует Benefit per order)

Логистические показатели:
* Days for shipping (real) — фактическое количество дней, затраченных на доставку
* Days for shipment (scheduled) — плановое количество дней на доставку
* Order Status — статус заказа
